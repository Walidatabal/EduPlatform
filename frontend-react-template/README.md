# React Frontend Template Direction

This API project is ready for a modern React frontend.

Recommended stack:
- Vite + React
- TypeScript
- Axios
- React Router
- React Query
- Tailwind or Bootstrap

Main screens:
- Login/Register
- Course Catalog
- Course Details
- Student Dashboard
- Teacher Course Builder
- Admin Dashboard
- Cart/Checkout
- Progress/Course Player

API base URL in Docker:

```text
http://localhost:8080
```
